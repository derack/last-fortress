# 4. Asset Pipeline را کامل و مقاوم کن

==================================================

سیستم فعلی را Audit کن.

باید موارد زیر تضمین شود:

* GLB موجود → Load واقعی
* GLB خراب → Crash نشود
* GLB ناقص → Fallback
* GLB بدون Animation → Procedural Animation
* GLB دارای Skeleton → AnimationMixer
* GLB دارای VFX Points → استفاده از نقاط واقعی
* نبود VFX Point → Synthetic Point
* Scale متفاوت → normalize
* Rotation متفاوت → rotationOffset
* Asset تکراری → Cache
* Enemyهای زیاد → Clone/Pool
* حذف Enemy → dispose صحیح
* تغییر Stage → Memory Leak نداشته باشد

هیچ Asset خراب نباید باعث Crash کل بازی شود.
