CHAPTER 05 — PRODUCTION WORKFLOW
۵ — گردش کار تولید: AI سه‌بعدی + Blender + Mixamo

گردش کار رسمی چهار ایستگاه دارد: (۱) تولید مدل پایه با ابزارهای متن-به-سه‌بعدی (Meshy / Tripo / Rodin) یا آرتیست؛ (۲) پاک‌سازی و کاهش چندضلعی در Blender؛ (۳) Rig و انیمیشن با Mixamo (کاراکترهای انسان‌گونه) یا دستی (چهارنفس، اژدها)؛ (۴) خروجی GLB و پذیرش در گالری بازی. هر کارت از فصل‌های ۶ تا ۹، پرامپت آمادهٔ ایستگاه ۱ را دارد؛ این فصل بقیهٔ مسیر را گام‌به‌گام قفل می‌کند.

۵.۱ — ایستگاه ۱: ابزارهای AI سه‌بعدی

مسیر پیشنهادی مسیر دو-مرحله‌ای است: اول یک Concept دو-بعدی (تصویر) با متن پرامپت کارت تولید کنید، بعد با حالت Image-to-3D مدل بگیرید؛ کیفیت و کنترل Silhouette به‌مراتب بالاتر از Text-to-3D خالص است. تنظیمات پیشنهادی همهٔ ابزارها: Symmetry = ON (به‌جز اژدها و عنکبوت در جزئیات ثانویه)، PBR = ON، Topology = Quad، هدف چندضلعی: بالاترین حالت ابزار (کاهش بعداً در Blender انجام می‌شود)، خروجی: GLB یا FBX.

Master Style Prompt (شروع همهٔ پرامپت‌ها — در کارت‌ها با [CHARACTER] جایگزین می‌شود):
Stylized dark fantasy game character, mobile tower-defense style, strong readable silhouette, hand-crafted feel, chunky readable armor shapes, PBR metal-rough, warm earthy palette with golden accents, clean topology, single mesh group, T-pose / A-pose, centered, full body, [CHARACTER], 3/4 hero pose, no text, no logo.

Negative Prompt سراسری (به همه اضافه شود):

photorealistic face, anime eyes, Roblox proportions, Marvel Thor, Mjolnir disc hammer, red cape, copyrighted characters, realistic human skin, messy topology, double shells, floating parts, asymmetry errors, baked shadows in albedo, neon oversaturation, blurry textures, text, watermark.

هر پرامپت کارت، توصیف اختصاصی [CHARACTER] است و با دو قطعه بالا کامل می‌شود. اگر ابزار از Image-to-3D پشتیبانی نمی‌کند، همان متن را مستقیم در Text-to-3D بدهید و نتیجه را با آزمون Silhouette فصل ۳ بسننجید؛ رد شدن = بازتولید، نه رتوش در Blender.

۵.۲ — ایستگاه ۲: پاک‌سازی در Blender

  1. Import: File → Import → glTF 2.0. بررسی اول: مدل رو به +Z؟ پاها روی Y=0؟ اگر نه، همین‌جا می‌چرخانیم و Ctrl+A → All Transforms می‌زنیم.
  2. ادغام مش‌های اضافی: قطعات ریز را به حداکثر ۳ مش برسانید (Ctrl+J)؛ چیزهای شناور بدون کاربرد حذف شود.
  3. کاهش چندضلعی: سقف‌های فصل ۴: قهرمان 15k، دشمن 10k، Boss 35k، برج 12k. مسیر: Decimate Modifier (Collapse) با Ratio آزمایشی 0.4–0.6 و بررسی Viewport Overlays → Statistics. UVها را قبل از اعمال چک کنید که نپاشند.
  4. نام‌گذاری: مش‌ها {id}_body و…، متریال‌ها MAT_{id}_{part}؛ نود بی‌نام نماند.
  5. بررسی متریال: Principled BSDF؛ شفافیت حذف (Opaque)؛ Emissive فقط نقاط کانونی؛ تعداد متریال ≤ ۳.
  6. Export FBX برای Mixamo: فقط مش انتخابی، Scale 1.0، Forward = −Z? — دقت: Mixamo مبدأ FBX خودش را دارد؛ خروجی با پیش‌فرض Blender + تیک Apply Transform بدهید و در ایستگاه ۳ دوباره جهت را وارسی کنید.

۵.۳ — ایستگاه ۳: Rig و انیمیشن با Mixamo (گام‌به‌گام)

  1. Upload: FBX کاراکتر را در mixamo.com بگذارید؛ در ویزارد Auto-Rigger، نشانگرها را روی چانه، مچ‌ها، آرنج‌ها، زانوها و کشاله بگذارید و «Next» را تا پایان بزنید.
  2. کلیپ‌ها: از کتابخانهٔ Mixamo نزدیک‌ترین Idle / Walking / Running / Any Idle Attack / Hit React / Death / Cheer را انتخاب کنید؛ Speed و Arm-Space را طوری تنظیم کنید که ژست پایه با کاراکتر بخواند.
  3. دانلود: اولین کلیپ را With Skin (FBX Binary، 30fps) بگیرید؛ بقیهٔ کلیپ‌ها را Without Skin با همان تنظیمات دانلود کنید — اسکلت همه یکسان است و در Blender مستقیم روی همان استخوان‌ها می‌نشیند.
  4. Import به Blender: هر ۸ (یا ۵/۹) فایل را در یک صحنه بیاورید؛ هر فایل یک Action می‌سازد.
  5. پاک‌سازی نام استخوان: پیشوند mixamorig: را حذف کنید (اسکریپت کوچک یا دستی روی ۲۰ استخوان اصلی) تا تطبیق نقطهٔ spine02 → ChestPoint تضمین شود.
  6. تغییر نام Action‌ها: دقیقاً به قرارداد فصل ۴: Idle، Walk، Run، Attack، Skill، Hit، Death، Victory. برای Skill و Victory، از کلیپ‌های نزدیک Mixamo رتاگِ دستی جزئی (۸–۱۲ فریم اصلاح پوز ژست نمادین) کافی است.
  7. In-Place کردن: اگر کلیپ جابه‌جایی ریشه دارد، منحنی X/Y جابه‌جایی Hips را حذف کنید (فقط bob عمودی بماند).
  8. حفظ اکشن‌ها: هر Action را یا در NLA Editor → Push Down ببرید یا Fake User (F) فعال کنید — وگرنه در خروجی GLB گم می‌شود. این رایج‌ترین گم‌شدگی انیمیشن در کل این گردش کار است.

Rig دستی (عنکبوت، پرنده، اژدها): Mixamo این‌ها را نمی‌پذیرد؛ اسکلت فصل ۴ را دستی بسازید، Skin Weight بدهید و کلیپ‌ها را با کلید-فریم دستی از روی توصیف صحنهٔ جدول ۴.۵ بسازید. برای اژدهای سیاه، سرمایه‌گذاری اصلی روی Roar، SpecialAttack (نفس سایه) و چرخهٔ بال‌زدن Idle/Walk است؛ همین سه، ۸۰٪ حس Boss را می‌سازند.

۵.۴ — ایستگاه ۴: خروجی GLB

  1. نقاط VFX: Emptyهای نام‌دار فصل ۴ را بسازید و به استخوان مربوط Parent کنید (WeaponPoint → WeaponBone، ChestPoint → Spine2، …)؛ جهت +Y هر Empty به سمت بیرون/جلو.
  2. Export: File → Export → glTF 2.0 (.glb) — Format = glTF Binary؛ Include = Selected Objects؛ Transform = +Y Up (پیش‌فرض)؛ Data = Apply Modifiers ✓، UV Maps ✓، Normals ✓؛ Material = Export؛ Animation = Animation mode: Actions با تیک همهٔ Actionهای هدف، Sampling ✓، FPS صحنه = 30.
  3. ممنوع: تیک Draco Compression (لودر فعلی پشتیبانی نمی‌کند)، تیک Shape Keys بی‌استفاده، تکسچر بالاتر از سقف کلاس.
  4. سنجش حجم: فایل را با سقف جدول ۴.۳ بسنجید؛ اگر سنگین است اول تکسچر را JPG/فشرده‌تر کنید (بزرگ‌ترین سهم)، بعد دوباره نگاه به مثلث‌ها.

۵.۵ — پذیرش در بازی (Drop-in)

  1. فایل را در مسیر دقیق جدول ۴.۷ بگذارید (public/assets/3d/…).
  2. سرور dev را بالا بیاورید و ?gallery=1 را باز کنید: نشان «مدل واقعی GLB» باید سبز شود؛ ارتفاع نمایش‌داده‌شده باید با targetHeight برابر باشد؛ هر کلیپ را از منوی گالری یک‌بار اجرا کنید.
  3. نبرد واقعی: کاراکتر را بکار بگیرید و سه چیز را ببینید — Crossfade نرم بین حرکت‌ها، خروج VFX از نقطهٔ درست (به‌ویژه برق چکش آرمان که باید با تاب سلاح حرکت کند)، و نبود پاز/افت فریم هنگام Spawn دسته‌ای.
  4. چک‌لیست کامل پذیرش در فصل ۱۰ است؛ فقط بعد از تیک همهٔ بندها، دارایی «تحویل‌شده» حساب می‌شود.
