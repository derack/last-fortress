   167→# 4. Asset Pipeline را کامل و مقاوم کن
   168→
   169→==================================================
   170→
   171→سیستم فعلی را Audit کن.
   172→
   173→باید موارد زیر تضمین شود:
   174→
   175→* GLB موجود → Load واقعی
   176→* GLB خراب → Crash نشود
   177→* GLB ناقص → Fallback
   178→* GLB بدون Animation → Procedural Animation
   179→* GLB دارای Skeleton → AnimationMixer
   180→* GLB دارای VFX Points → استفاده از نقاط واقعی
   181→* نبود VFX Point → Synthetic Point
   182→* Scale متفاوت → normalize
   183→* Rotation متفاوت → rotationOffset
   184→* Asset تکراری → Cache
   185→* Enemyهای زیاد → Clone/Pool
   186→* حذف Enemy → dispose صحیح
   187→* تغییر Stage → Memory Leak نداشته باشد
   188→
   189→هیچ Asset خراب نباید باعث Crash کل بازی شود.
